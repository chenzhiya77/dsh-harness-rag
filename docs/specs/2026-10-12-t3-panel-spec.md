## 1. 问题

### 1.0 一眼看懂

**现状**：DSH 插件面板是占位串（「知识库面板（骨架占位，T3 实装）」）——装着插件只能靠对话里的 `hrag_*` 工具，人没有可操作的面。

**本对**：把面板写成真界面——**功能面＝DeerFlow 工作台知识库页的全部**（管理＋可视化）。UI 全部新写在插件（DSH slot API＋DSH 组件词汇），**对照原型是工作台**（功能对齐、代码不搬）；数据走 **T2 已验收的同一套 REST**（host 半薄代理；deer-flow 前端零改动）。

```
改的（插件仓）                          不改的
──────────────                          ──────────────
① client.js 面板内容（占位→真壳）        deer-flow 前端全部（对照原型）
② host 半薄代理（面板数据缝）             T2 工具面（五工具已收）
③ 同文件视图分区（管理＋切片＋召回＋     后端路由（缺路由⇒停下待裁）
   上传/重建＋投影＋图谱＋评测）          摄取后台与长任务呈现（T4）
```

### 1.1 空间可达性（10-12 实测，D5 翻案依据）

- 宿主右栏＝dockkit 停靠系统：**拖宽（`resizeSplit`）/ 分栏（两格上限）/ 面板全屏（`pane.fullscreen.toggle`）/ 浮动面板**四种形态（实读 `dsh-client-ui-sidebar-right/lib/client.js`）。
- 连宿主文案都自认可变：「栏宽不足，**拖宽侧边栏后再分栏**」。
- ⇒ 原 10-10 判断「重型可视化留 DeerFlow（右栏放不下）」**前提错误**：`无整页槽`（槽位机制）≠`无大空间`（用户可达）。**D5 翻案为全保留**。

### 1.2 现状核对（2026-10-12）

- 面板入口已就位（T1）：右栏 tab 注册＋引导胶囊＋`openTab`；面板内容＝占位 `<div>`（`client.js`）。
- 数据面：T2 已验收的 REST（recall-test 带 `path`／chunks 带 `chunk_id` 窗／documents／库 CRUD…）；**管理动作与可视化端点全部既存**（工作台在用），面板只需成为新消费者（Task 0 逐条实名）。
- 视图参照：工作台知识库页（切片抽屉＝跳转+高亮；召回面板＝三路；向量/图谱/评测 tab 各在）。

## 2. 决定

### D1 —— 面板功能面（**已裁：全做**）

- **裁定**：库/文档/切片/召回/续读 ＋ **管理动作（删除·重试·重建索引入口）**。
- **边界**：危险动作带闸——删除=确认对话框（级联影响如实展示）；切片删除=**删除预览**（孤儿实体/受影响关系/受牵连条目，照工作台语义）；重试=只对 failed/降级文档出现（409 语义照后端）。
- **代价**：管理动作是"执行级"交互（误点代价＝丢索引），所以闸必须照抄工作台，不能简化成两键式。

### D2 —— 上传入口（**已裁：甲**）

- **裁定**：入口＋提交动作（多文件）；**进度/失败呈现归 T4**（`ctx.jobs` 接线时补齐）——首期留"进度位"。
- **边界**：上传与重建索引同一口径（入口＋提交＋进度位留白）；页面刷新后列表可见（状态如实）。

### D3 —— 数据缝（**已裁：甲**）

- **裁定**：面板经 **host 半薄代理**（与工具面同一条 `api()`；client 侧转发）。
- **判据**：凭证不进页面；CORS/双基址零配置。
- **代价**：面板视图多一跳（loopback，可忽略）。

### D4 —— 召回测试形态（**已裁：乙**）

- **裁定**：照现状三段展示（query/top_k；结果三段＋分数标签；未请求路段不出现——三路全跑）。
- **为什么乙**：现状 UI **无**"只选一路"按钮（单路是插件工具侧诉求）⇒ 单路选择进 §6 缺口（优化另案），与"先一致"基调同构。

### D5 —— 视图归属（**已裁：全保留**，10-12 翻案）

- **裁定**：库/文档/切片/续读/召回/上传/管理动作 ＋ **向量投影＋图谱画布＋评测视图**（工作台对应功能的全部）。
- **判据**：§1.1 空间可达；功能对齐优先。
- **代价**：可视化需在 DSH 内**新建**（拾取/缩放/布局/联动重做，代码不搬）；执行序后置（§3 表末）。
- **验收口径**：交互可比工作台精简，**功能不缩**（README 表述随此）。

### D6 —— 面板形态适配（**已裁：延后**）

- **裁定**：视图先按默认宽＋"可伸展"姿态写；拖宽/全屏/浮动三档细体验**前端完工后慢慢调**（不在本对验收面）。
- **登记**：§6 缺口表。

## 3. 接口契约

### 3.1 数据缝（host 半薄代理）

- 新增 `kb_proxy` 组：每个面板动作一个薄函数（透传＋错误规范化），全部走既有 REST；**panel 侧不持 base URL/凭证**。
- 缺路由情形：**停下进待裁**（本对不许顺手改后端）。

### 3.2 面板结构（`client.js` 单文件，内部分区）

- 壳：顶部（库选择/刷新/上传入口位）＋分区（文档｜召回｜投影｜图谱｜评测）＋空/加载/错三态；切片查看＝**右侧抽屉**（照工作台 Sheet：点文档行/召回命中行开）。
- 视图份额（对照 §2 D5 视图归属）；i18n 词条全走 locale 服务（内联字典注册，官方三方模式；`locale/{zh,en}.json` 仅承载显示元数据）。（单文件形态与取证见 plan Task 0 ⑥——一包一个自包含 `client.js` 是宿主装载的硬形态。）

### 3.3 管理动作闸（逐动作）

| 动作 | 闸 | 口径来源 |
| --- | --- | --- |
| 删除文档 | 确认对话框（级联影响如实展示） | 工作台同款 |
| 删除切片 | **删除预览**（先看后删） | `delete-preview` 路由语义 |
| 重试文档 | 门控（failed/降级才出现；409 照后端） | `retry` 路由语义 |
| 重建索引 | 确认级＋进度位（T4 接轮询） | `reindex` 路由语义 |

## 4. 验收

1. **一条龙**：开面板→建库/选库→上传→查切片→续读→删除切片（预览流）→召回测试→删除文档→重建索引→投影→图谱→评测视图，全程面板内完成；
2. **对照工作台**：召回/切片/投影/图谱各抽一题同库对照（数据一致）；
3. **管理动作闸**：删除确认、删除预览、重试门控、重建确认——四闸逐项过；
4. **数据缝**：面板请求全部经 host 代理（页面无 base URL/凭证）；devtools 抽查；
5. **deer-flow 零改动**：`git diff` 仅文档；
6. **i18n**：面板词条全走 locale；
7. **门禁**：插件侧编译探针＋桌面端整重启真跑（模块代体检法见步骤记录 §8）；全部 `**实测**` 行回填。

## 5. 影响面

**改的（插件仓）**：`client.js`（单文件重写：拆占位＋各视图分区）／host 半（薄代理）／`locale/`（词条）／README（T3 交付描述与早期状态注修）。
