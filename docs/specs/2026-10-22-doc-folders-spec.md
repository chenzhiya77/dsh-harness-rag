## 1. 范围

本对只改插件仓 `client.js` 的文档 tab，六件：

1. **文件夹分组**：新建、改名、删除；每篇文档至多归属一个文件夹；无归属/失效归属归「未分类」。
2. **组行折叠**：文件夹在表内以整行组头呈现，可收起为一条文件夹栏、可再展开；折叠状态 per-kb 持久。
3. **文档移动**：单篇/批量移动到文件夹或「未分类」；移动即生效，不刷新、不请求后端。
4. **名称表头**：点击「名称」表头按名称排序（首点升序、再点切换），把当前空着的点击动作补上。
5. **图标与颜色**：每个用户文件夹与「未分类」可选 15 种线条图案与 10 种颜色，任意组合；per-kb 本地持久，点选即生效。
6. **文件夹排序**：用户文件夹组行可前后拖拽重排，顺序 per-kb 本地持久；「未分类」固定最后、不可拖。

**不包含**：引擎/API/`documents.folder_id` 持久化；每文件夹独立列；嵌套文件夹；按文件夹检索；上传时选目标文件夹；agent 工具可见性；跨端/跨 profile 同步。

## 2. 现状与依据

### 2.1 文档表现状（10-22 只读）

- 表是 fixed 布局，一个吸顶表头（`client.js:1943-1945`），列显隐 per-kb（`hrag-doc-table-prefs.<kbId>`，`client.js:8379-8417`），排序四字段＋手动序（`hrag-doc-order.<kbId>`，`client.js:8208-8268`），行拖拽只在可拖时挂 `draggable`（`client.js:8828-8857` / `9251-9317`）。
- 「名称」表头是一个裸 `th`（`client.js:9183`），没有点击、没有菜单；其他可隐藏列表头才有 chevron 列菜单（`client.js:9122-9144`）。排序入口目前只在工具栏的排序菜单（`client.js:9037-9073`）。
- 行渲染直接在 `visibleDocs.map` 里铺 `<tr>`（`client.js:9210-9400`），列表只有一层，没有组行概念。
- 行 ⋯ / 右键菜单由 `docRowMenuItems` / `docContextMenuItems` 生成（`client.js:8450-8489`）；批量动作按 `selectedIds` 走。
- 搜索词非空或多选非空时禁止拖拽（`canDrag`，`client.js:8837`）；搜索变化会清选择集（`client.js:9014-9019`）。

### 2.2 已有分组先例：百科卡片抽屉（本地分区）

- 工作台 `card-drawers.ts` 头注明确：**localStorage by design**——分组是小的、个人的、装饰性的，后端只存卡片本身；membership 是分区，每卡至多一屉；删抽屉只掉归属，不动卡片。
- 插件逐字移植为 `hrag-card-drawers.<kbId>.v1`（`client.js:13531-13533`），模型 `{ drawers, membership }`，并已有 create/update/delete/hide/reveal/move 全套本地动作（`client.js:13594-13708`）。
- 「移动到抽屉」已用宿主菜单 **submenu**（`client.js:14956-14962`），当前抽屉打勾并置灰；批量移动单次 persist（`client.js:13694-13696`）。
- 该先例直接回答了本对的落点：文档文件夹同样是个人归类，v1 走同一套本地分区，不动引擎。代价是清缓存/换 profile 丢归属、agent 工具看不见——与百科抽屉完全一致。

### 2.3 工作台没有文档文件夹

工作台文档表（`document-panel.tsx`）没有文档文件夹/分组；本功能是插件增加，收口时在 `docs/equivalence.md` §2 登记「有意偏离，分组模型照 card-drawers 的本地分区口径」。

### 2.4 为什么 v1 不落引擎

- 上一轮曾把文件夹归为「文档元数据、建议落引擎」；核实到卡片抽屉的既有设计后修正：当前需求是**个人归类展示**，不是检索范围，也不是跨端共享数据。
- 引擎版需要 `kb_folders` 表＋`documents.folder_id`＋folders API＋迁移（当前 head 0019）＋插件 proxy，跨两仓；收益是清缓存/换端不丢、工具可见，但这些都是当前未提出的需求。
- 升级路径见 §8：同一份 `{ folders, membership }` 可原样抬到引擎，届时另立一对，不在本对预埋半套。

### 2.5 现有交互接缝

- 排序：分组发生在 `docsSort` / `applyManualOrder` 之后，组内维持当前排序。
- 拖拽：现有行拖拽的手动序是全局 id 序列；同文件夹内拖行＝重排，跨文件夹拖行＝移动归属（只改 `membership`，不写手动序）。
- 选择：全选/批量动作必须只覆盖当前展开且过滤后的行；折叠/删文件夹（含未分类）要清掉不可见选择，沿既有「搜索清选择」的安全口径。
- 上传：上传链在面板壳层，`refreshToken` 后重取清单；新文档无 membership，自然落「未分类」。

## 3. 决策表（D1–D5＋D4b；D4 已拍甲，其余已按建议落改、待终审）

### D1 —— 形态（建议：甲＝一张表＋组行）

- **甲（建议）**：保留**一个全局吸顶表头**；文件夹是 `<tbody>` 里的整行组头（`td[colspan]`），组头下铺该文件夹的文档行；折叠只隐藏该组文档行，组头留成一条文件夹栏。
- **乙**：每个文件夹自带一行表头（他最初的想法）——收起时表头变文件夹栏，展开时是属性行。
- 判据：乙能天然支持「每个文件夹一套列」，但多文件夹同时展开会重复表头、列宽/横滚/吸顶各走各的，排序、全选、搜索都要按组重定规则；名称表头还会同时承担「收起」和「排序/双击改名」，点击语义打架。甲保留现有表格的全部交互，先付零列配置成本。
- 若以后类型专属列真的成立（如视频时长/镜头数），再评估乙或全局加列；数据模型不变。

### D2 —— 归属落点（已拍：本地 localStorage）

- 键：`hrag-doc-folders.<kbId>.v1`；值：`{ folders: [{ id, name, collapsed? }], membership: { [docId]: folderId }, unfiledCollapsed?: true }`；未分类的折叠位是顶层布尔，不混进 `folders`。
- 与 `hrag-card-drawers.<kbId>.v1` 同族、同 posture：读失败/坏 JSON 回退空态，写失败 best-effort；切库重读，不把旧库状态写进新库键。
- 零引擎、零 API、零 host 半改动；检索链路完全不读这份数据，用户可见的检索行为不变。
- 已知代价（接受）：清浏览器站点数据/换 profile 会丢归属；不跨端共享；agent 工具看不到文件夹。

### D3 —— 分区语义（建议：甲＝至多一屉，未分类兜底）

- **甲（建议）**：每篇文档至多归属一个文件夹；无 membership 或指向已删文件夹 ⇒「未分类」；删文件夹只删它的 membership，**绝不动文档**；删文档留下的失效 membership 无害（分组时忽略）。
- 乙：一篇可进多个文件夹（标签式）。会引入多归属、重复行、计数口径，和「文件夹」语义不符；不做。
- 文件夹顺序：新建置顶（最新在前），「未分类」恒最后；用户文件夹可拖拽重排（§4.5），顺序 per-kb 持久。
- **零文件夹时维持平表**：不渲染用户文件夹组行，也不渲染「未分类」组行；表仍是当前一张平表（名称表头排序是唯一新增入口）；出现第一个用户文件夹后，才进入分组形态。
- 「未分类」有文档时渲染在最后；可收起/展开（顶层 `unfiledCollapsed`）；有 ⋯ 与右键菜单（图标与颜色、重命名、新建文件夹、收起/展开），可改名（顶层 `unfiledName`）、不可删除；为空时不占行（仍可从移动菜单选它）；从空变为有文档时自动展开。

### D4 —— 名称表头动作与收起落点（已拍甲）

- **甲（拍定）**：名称表头整格可点＝按名称排序（首点 `name`＋`asc`，已是 `name` 则反转）；工具栏排序菜单仍是完整入口，勾选同步；排序只作用于组内文档，不重排文件夹。收起动作放在组行上（用户文件夹与未分类同式；文件夹图标/行点击），因为收起的是某一个组，不是整张表。
- **可发现性**：表头加 `cursor:pointer`、`title`「按名称排序」；hover 出双箭头（复用排序菜单的 `ChevronsUpDown`），激活时显示升/降箭头（ArrowUp/ArrowDown，宿主缺件自绘；12–14px、gap 2，Task 0 钉）；箭头常驻占位、仅 opacity，不挤标签；`th` 可聚焦（`tabIndex=0`），Enter/Space 同点击，`focus-visible` 出焦点环；`aria-sort` 随模式给 `none/ascending/descending`。其他列的列菜单 chevron 不复用。
- **点击边界**：左键排序；右键仍开列菜单（现有 `tr` 右键）；排序不清选择、不改列偏好；只名称表头有直接排序，其他表头的动作是列菜单 chevron——有意不对称（名称列钉死、无列菜单），不给其他表头加点击排序。
- **乙（不做）**：点名称表头收起整表。真正的反对理由：①点表头＝排序是通用预期，点表头收起会与行序反馈混淆；②「收起整表」是另一个状态——表头/表体/底栏是保留还是收成一条「文档 (N)」、收起态存哪里，都要单独定义，不是 A 形态的组行折叠；③零文件夹时没有组行/文件夹栏可落，收起后的形态没有定义。若以后确实要整表收起，另立显式控件（D4b），不占用名称表头。
- **组行点击/双击**：用户文件夹＝文件夹图标/行点击立即切换；名称单击延迟 220ms、双击取消并改名；未分类名称/图标/行点击都立即切换，双击不改名；右键/⋯ 开未分类菜单（图标与颜色、重命名、新建文件夹、收起/展开），不进文档行菜单。
- **表头常驻**：即使所有文件夹都收起，列头仍是排序/列设置/全选的锚点，不隐藏；不做「表头变文件夹栏」。

### D4b —— 全局收起（拍定：本对不做，留作另立）

- 本对只做「按文件夹收」；零文件夹时表格保持原样，不提供整表收起。
- 若以后需要「整块文档区收成一条」，另立显式控件（表头左侧按钮或工具栏按钮）与持久态；不复用名称表头，不塞进本对。

### D5 —— 创建/改名/移动形态（建议：甲＝行内编辑＋宿主子菜单）

- **甲（建议）**：
  - 新建：工具栏文件夹加号；在用户文件夹最上方出一条**草稿行**（输入框聚焦），Enter 提交、Esc 取消、失焦有效则提交；提交后仍在最上方（新建置顶）。
  - 改名：双击组行名称或右键菜单进入**行内输入**；Enter 提交、Esc 取消、失焦有效则提交；空名取消，完全同名报行内错误并留在编辑态。
  - 移动：沿百科抽屉的宿主菜单 **submenu**——「移动到文件夹 ▸ 未分类 / 各文件夹」；当前目标打勾并置灰；单篇/批量同一入口；批量只 persist 一次。移动后自动展开目标文件夹，选择集保留。
  - 删除：组行 ⋯／右键 → 确认弹层（含该文件夹篇数）；确认后文档移入「未分类」（若收起则展开），清掉这些文档的选择；不删文档。
  - 子菜单沿用宿主（百科抽屉同款）；宿主子菜单不翻转是已知行为，若真栈里贴近底部被裁，回退为同一数据模型的小弹层选择，不改其余决策。
- **乙**：新建/改名都开卡片抽屉同款弹层（名称+图标+颜色）。本需求只要名称，弹层多一步且插入图标/颜色是额外范围；行内编辑与表格密度一致，故不选。
- 移动菜单不提供「新建文件夹并移动」；新建入口统一在工具栏，避免一次动作跨两套状态。

## 4. 口径

### 4.1 形态与组行

```text
[搜索]                         [+ 文件夹] [排序] [列]
☐ 名称     状态    上传者   时间    大小   切片
[folder] 产品文档                             ⋯
    ☐ ...
[folder] 会议录像                             ⋯
[folder] 未分类                               ⋯
```

- 用户文件夹按存储序（新建置顶）渲染；「未分类」最后；两者都可收起，且都有文件夹图标按钮、⋯ 与右键组菜单。
- 组行不显示篇数；原篇数位置改为该组全选框（鼠标悬浮、聚焦、已勾选/半选或表格进入选择态时显现）；空文件夹也渲染，呈禁用态（无可选文档）。
- 组行去掉下拉箭头；展开/收起由文件夹图标按钮承担（用户文件夹与未分类同式）。默认文件夹图标不旋转，用两态表达：收起＝线条文件夹，展开＝蓝色实心文件夹（内面 0.16 填充＋蓝色字形，照 DSH 侧栏工作区）。选了其它图案时收起为线条、展开为同色实心填充（fill=currentColor），不再加底块。`aria-expanded` 与文档行渲染同步。图标按钮点击不触发组行其它点击。
- 用户文件夹组行：文件夹图标按钮＋名称＋右侧组全选框＋⋯；未分类组行同式；未分类菜单＝图标与颜色、重命名、新建文件夹、收起/展开，不可删除；名称单击仍立即切换，双击不改名。展开/收起只改变该组文档行是否渲染。
- 组全选框只作用于该组文档：组内全选/全清；部分选中显示 indeterminate；对已收起的组点击全选会先展开该组，避免选中隐藏行；其它组的已选文档不受影响。
- 组行点击切换排除文件夹图标按钮、组全选框、⋯ 与改名输入框；⋯ 点击只开菜单，不切换折叠；右键另开组行菜单（未分类为重命名/新建文件夹/收起展开）。未分类名称单击立即切换（无 220ms、无双击改名）。
- 组行文件夹图标与表头全选框同列（按钮 4..24，14 字形 7..21 vs 框 8..21），组名左缘 32 对「名称」表头；文档行的类型徽章 32／名称 60 不变。
- 组行/空提示行的 `colspan`＝1（复选）＋1（名称）＋可见数据列＋1（操作）；隐藏列时重算。
- 组行不挂 `draggable`，也不是 drop 目标。
- 用户文件夹组内无文档时展开显示一行「此文件夹为空」；空用户文件夹保留（可接收移动）。
- 「未分类」为空且已有用户文件夹时不渲染组行；零文件夹时不渲染任何组行（平表，名称表头排序为唯一新增入口）；未分类从空变为有文档时自动展开。
- 组行不吸顶（滚动时随表走），v1 不做 sticky 组头。

### 4.1.1 图标与颜色（10-22 追加五）

- 入口：用户文件夹与「未分类」组行的 ⋯/右键 →「图标与颜色」。
- 图案 15 种：文件夹（默认，宿主两态）＋披萨、冰淇淋、樱桃、鱼、小鸟、兔子、叶子、云朵、月亮、雨伞、耳机、手柄、调色盘、相机。全部为 24×24、2px 线宽的单色线条节点，与宿主图标同笔触；不照搬外部参考项目的原套图案。
- 颜色 10 种（灰/墨绿/绿/蓝/琥珀/红/粉/靛蓝/橙/青绿）＋「默认」无色项；与图案自由组合，点选即写 `folders[].icon`/`folders[].color`（未分类写顶层 `unfiledIcon`/`unfiledColor`）并即时改组行；「恢复默认」清两键；删除最后一个用户文件夹时随未分类组一起丢弃。
- 弹层：上一排样式（15 钮，30×30，标题为图案名）、下一排颜色（圆点），宽 536（视口更窄时收缩、样式换行），锚在组行图标按钮下方/上方；Esc/点遮罩关闭。
- 颜色走 `--hrag-folder-tone-*`，浅/深主题两套值；非默认图案的展开态走实心填充（`fill=currentColor`、线宽 1.5），跟随所选颜色。

### 4.2 新建/改名/删除

- 用户文件夹支持新建/改名/删除；「未分类」支持改名，不支持删除（菜单＝重命名、新建文件夹、收起/展开）。
- 新建入口只在 `phase === 'ready'` 且搜索词为空时可用；草稿行在用户文件夹最上方（输入聚焦）；空名/纯空白取消；完全同名（trim 后、区分大小写）或等于自定义未分类名时，报行内错误并保留输入；提交后置顶且展开。
- 用户文件夹改名入口：双击名称、右键菜单「重命名」；未分类改名入口仅 ⋯/右键「重命名」（名称单击仍是立即折叠，不提供双击改名）。空名取消并恢复原名；与其它文件夹或自定义未分类名同名时报行内错误；成功后折叠状态不变。
- 未分类改名存顶层 `unfiledName`，只改显示名；清空取消；改回默认「未分类」即删除该键、恢复默认文案。归属规则不变（无 `membership` 的文档仍归该组）。
- 删除入口：组行 ⋯／右键「删除文件夹」；确认弹层文案说明「其中 N 篇文档会移到{未分类显示名}，文档不会被删除」；确认后删文件夹＋membership，清掉 `unfiledCollapsed`（未分类若收起则展开），清这些文档的选择；删除后若仍有文件夹则保留 `unfiledName`，删除最后一个文件夹时一并丢弃。
- 删除最后一个用户文件夹后回到零文件夹形态（无组行、无未分类行）。
- 切库时草稿、改名输入、打开的组行菜单一并清空（连同既有拖拽/选择状态），不把旧库的编辑态带进新库。

### 4.3 移动

- 入口：行 ⋯ 与行右键的「移动到文件夹」子菜单；批量态同项。子菜单项＝未分类显示名（默认「未分类」或自定义 `unfiledName`）＋各用户文件夹；当前归属打勾并置灰；批量选择跨多个文件夹时无任何目标打勾。零文件夹（平表形态）时不渲染该入口。
- 搜索词非空时该入口置灰（与拖拽禁用同口径，避免移动结果被过滤掉、选择集藏进不可见行）。
- 移动只改 `membership`，单篇/批量都不发请求；批量单次 persist。
- 移动后自动展开目标文件夹（含未分类：清掉 `unfiledCollapsed`），保持选择集。
- 移动不改 `hrag-doc-order` 的 id 序列；文档在目标组内的位置按现有全局 id 序落位，不置顶也不置底。
- 跨组拖行＝移动：把文档行拖到目标组行（含空态行）或该组任一文档行，松手只改 `membership`；目标组自动展开。拖回当前组为 no-op；组行本身不可拖。

### 4.4 折叠/搜索/选择

- 折叠：用户文件夹写 `folders[].collapsed`，未分类写顶层 `unfiledCollapsed`；组行文件夹图标/行点击切换，组全选框点击不切换折叠；用户文件夹名称单击走 220ms 防抖，未分类名称单击立即切换。
- 搜索词非空：只显示有命中的用户文件夹与未分类，**强制展开**（不改存储的折叠态）；清空搜索后恢复两类折叠态。搜索期间折叠/新建/移动置灰，避免与临时展开态冲突。
- 选择：表头全选＝当前展开且过滤后的文档；组全选框只作用该组文档，部分选中呈 indeterminate，收起组点击会先展开；折叠某组（含未分类）时清掉该组已选中的文档；删除文件夹时清掉该组选择；移动后目标自动展开、选择保留。
- 搜索变化清选择沿用现状（`client.js:9014-9019`）。
- 无命中时仍显示既有「没有匹配的文档」空态。

### 4.5 排序/手动序/拖拽

- 分组在排序之后：字段排序（含按名称）先排全表，再按文件夹归组；组内顺序即排序结果。
- 名称表头（D4 甲）：
  - 点击/键盘：整格左键与 Enter/Space 等价；首次设 `name`＋`asc`，已是 `name` 则反转；`aria-sort` 随模式给 `none/ascending/descending`，`tabIndex=0`，`focus-visible` 出焦点环。
  - 可发现性：`cursor:pointer`＋`title`「按名称排序」；hover/focus 出双箭头（`ChevronsUpDown`），激活时显示升/降箭头（`ArrowUp`/`ArrowDown`，宿主缺件自绘；12–14px、gap 2，Task 0 钉）；箭盒常驻占位、默认仅 opacity，不挤标签；其他列的列菜单 chevron 不复用。
  - 作用域：只重排组内文档，不重排文件夹（文件夹仍新建置顶）；不清选择、不改列偏好；工具栏排序菜单同步勾选。
  - 边界：右键仍开列菜单；排序与手动序互斥——点名称退出 manual，手动 ids 保留，点「手动排序」恢复。
  - 不对称：只有名称表头有直接排序；其他表头的动作是 chevron 列菜单；这是有意设计，不给其他表头加点击排序。
- 手动序：同一文件夹内拖行照旧切「手动排序」并写 `hrag-doc-order`；重排基准用**过滤后的全量文档 id**（含其它文件夹/已折叠组的文档），不能只用当前展开集，否则会把不可见文档挪位。
- 移动与手动序：移动只改 `membership`，`hrag-doc-order` 的 id 序列原样保留；文档在目标组内的位置跟随现有全局 id 序。
- 跨文件夹：拖到目标组行/空态行/异组文档行均接受 `dropEffect='move'`；悬停时高亮目标组行（`interactive-bg-hover`＋2px `button-primary-fill` 内环），不出插入线；drop 只改 `membership`，不写 `hrag-doc-order`，目标组由 `moveDocs` 自动展开。拖回当前组为 no-op。
- 搜索非空或多选非空仍禁用文档拖拽（现状）；拖拽收尾的 click 不触发组行折叠/名称延时切换。
- 文件夹顺序：用户文件夹组行可前后拖拽（组行可拖；搜索非空／草稿／改名／仅一个文件夹时禁拖）；悬停另一文件夹行按上/下半区显示 2px 插入线，drop 把文件夹移到该行前/后；悬停「未分类」行＝挪到末位。拖动源降至 0.45 透明度；落点后 300ms 抑制 click（不误触折叠）。只重排 `folders` 数组，membership/折叠态/图标颜色随文件夹一起移动，`hrag-doc-order` 不变；未分类不可拖，也不带拖动源的降透明/抓手样式（其 `group.id=null` 与空闲态 `folderOrderDragId=null` 同值，需按 `kind` 守卫）。

### 4.6 存储

- 键：`hrag-doc-folders.<kbId>.v1`；值：

```js
{
  folders: [{ id, name, collapsed?: true, icon?: string, color?: string }],
  membership: { [docId]: folderId },
  unfiledCollapsed?: true,
  unfiledName?: string,
  unfiledIcon?: string,
  unfiledColor?: string
}
```

- 清洗：`folders` 只收字符串 `id`/`name`，名称 trim 后非空；重复 id 首个胜；`collapsed` 仅在 `true` 时保留；`icon`/`color` 走图案/颜色白名单，未分类的 `unfiledIcon`/`unfiledColor` 同理；`unfiledCollapsed` 仅在 `true` 时保留，零文件夹时丢弃（平表无组行可收）；`unfiledName` 只收 trim 后非空字符串，零文件夹时丢弃；`membership` 只收字符串键值和字符串值；指向已删文件夹的映射保留但分组时忽略（与 card-drawers 同式）。
- `folders` 数组顺序即组行顺序（新建置顶；拖拽重排只改此数组，不写其它键）。
- 坏 JSON/缺键/读失败⇒空态；写失败⇒仅本次会话内存生效；切库重读，写侧用 `kbIdRef` 防旧库写新库（沿 `client.js:8723-8745` 先例）。
- 不迁移旧键（本功能无历史键）；文档删除留下的失效 membership 不做主动清扫，分组时自然忽略。

### 4.7 全选框/空态

- 组行不显示篇数/计数；组全选框的选中态由当前 `selectedIds` 与组内文档现算，不存冗余计数；空文件夹的组全选框为禁用态。
- 空库（`phase==='empty'`）不显示文件夹入口与组行，维持九宫格上传空态；已存的本地文件夹保留，首篇文档上传后重新出现。
- 新上传文档无 membership⇒未分类；若未分类此前为空被隐藏，会随文档出现并处于展开态；已在列表中被收起的未分类保持收起。
- 文档被删除后，其失效 membership 不影响分组与组全选框。

### 4.8 视觉

- 组行高 36px、无新底色、不画分割线（表头线保留）；hover 用 `interactive-bg-hover`。名称 13px/500 `label-primary`；组全选框 13px（复用行复选框样式）。
- 文件夹图标按钮在组行最左（按钮 4..24、14 字形 7..21，与表头全选框 8..21 同列），组名左缘 32 对齐「名称」表头；文档行不受影响（类型徽章 32、名称 60）。默认图案：收起态＝16×16 线条文件夹（2 路径、`label-tertiary`）；展开态＝16×16 实心文件夹（3 路径、内面 0.16 填充、`state-business-primary`，浅色 `#4176E6`）。自定义图案：14px（lucide 24×24 节点），收起＝线条、展开＝同色实心填充（`fill=currentColor`、线宽 1.5）。hover/focus 用现有交互底色与焦点环 token；不再渲染下拉箭头。
- 跨组拖行悬停：目标组行底色 `interactive-bg-hover`，并叠 2px `button-primary-fill` 内环；松手后回常态。空态行同受高亮。
- 组全选框位于原篇数位置（名称右侧、⋯ 左侧）；默认 opacity 0，hover/focus、已勾选、indeterminate 或表格选择态时显现；空文件夹为 disabled（hover 可见、不可点，光标 default）。
- 名称表头：`cursor:pointer`；hover/focus 时排序箭头显现（默认双箭头，激活时升/降箭头 `ArrowUp`/`ArrowDown`，12–14px、gap 2）；箭盒常驻占位、默认仅 opacity；`focus-visible` 用现有焦点环 token；箭头不挤压「名称」标签（552/570 档 Task 0 实量）。
- ⋯ 沿用行菜单样式，hover/focus 时显现；组行名称过长省略号截断，组名/⋯ 不被裁。
- 组行不新增 surface/tint，不吸顶，不加阴影；浅/深主题均走现有 token。
- 草稿行/改名输入沿用宿主 Input 或现有 `.hrag-input` 样式；错误行内显示，不开 toast。

## 5. 验收

1. **零文件夹回归**：文档表除名称表头新增排序入口外与改前逐项一致——列宽/横滚、列菜单、排序菜单、行拖拽、搜索、全选/批量、行 ⋯/右键、抽屉点击、上传链。
2. **新建/改名/折叠**：工具栏新建（草稿行）→ 文件夹出现且置顶（空文件夹显示禁用态组全选框）；双击改名、右键改名；未分类经 ⋯/右键重命名、改回「未分类」恢复默认；文件夹图标/行点击折叠与展开（无下拉箭头）；重开面板／切 tab／切库后文件夹、归属、折叠态（含未分类）与未分类自定义名保持；切库时草稿/改名/菜单状态清空。
3. **点击语义**：名称表头左键/Enter/Space 按名称排序（首点升序、再点反转，工具栏菜单同步）；hover/聚焦出排序箭头、激活时升/降箭头（`ArrowUp`/`ArrowDown`）正确，`aria-sort` 同步；右键仍开列菜单；排序只重排组内文档，不清选择/不改列偏好；手动序往返保留；组行名称单击折叠/展开（220ms）、双击进入改名；未分类名称单击立即切换、双击不改名，重命名走 ⋯/右键；文件夹图标按钮点击折叠/展开且不触发组行其它动作；组全选框点击不切换折叠；用户文件夹右键始终可改名；空名/同名/与自定义未分类名同名拦截正确。
4. **移动**：单篇/批量移动到用户文件夹与未分类；当前目标置灰打勾，跨多文件夹批量无勾；移动即生效、目标自动展开；手动序下移动不改全局 id 序，文档在目标组内按现有序落位；搜索词非空时入口置灰。
5. **删除文件夹**：确认弹层含篇数且说明不删文档；确认后文档归未分类、选择被清、未分类若收起则展开；删最后一个文件夹回到平表。
6. **搜索与选择**：搜索只显示有命中的组并强制展开（含未分类）；清空恢复两类折叠态；表头全选只覆盖展开行；组全选框只作用于该组文档，部分选中呈 indeterminate，收起组点击会先展开，空文件夹为禁用态；折叠/删文件夹（含未分类）清掉该组选择；批量删除不会命中隐藏行。
7. **排序/拖拽**：字段排序与名称表头排序在组内生效；手动模式同组拖拽生效且不挪动其它文件夹/折叠组的文档；跨组拖到组行/空态行/异组文档行＝移动归属、目标组高亮并自动展开、不写手动序、不出插入线；拖回当前组 no-op；搜索/多选禁拖照旧。
    - **文件夹排序**：拖文件夹组行到另一文件夹行下半区 → 插入线在下方、松手顺序互换且组未误折叠；拖到上半区 → 插到其前；拖到「未分类」行 → 挪到末位；重开／切 tab／切库后顺序保持；搜索/草稿/改名时组行不可拖。
8. **几何/主题**：570／740／满宽三档组行不撑破、不新增横滚；组行无分割线；隐藏列时组行/空提示行 `colspan` 重算正确；未分类行文件夹图标/⋯ 与用户文件夹行对齐；文件夹图标与表头全选框同列、组名与「名称」表头同列；图标收起/展开两态形状与颜色正确；组全选框位于原篇数位置且不挤组名；浅/深主题下组行、hover、拖放高亮、组全选框（含空文件夹禁用态）、⋯ 与现有表格层次一致；空文件夹提示对齐正确。
    - **图标与颜色**：用户文件夹与「未分类」的 ⋯/右键都有「图标与颜色」；15 个样式钮（默认文件夹选中）＋11 个色点（默认＋10 色）；选披萨/兔子等非默认图案后组行图标即时切换并落盘，展开态变为同色实心、收起回到线条；选色后图标着色且重开面板/切 tab 保持；「恢复默认」清两键回两态文件夹。
9. **本地容错**：坏 JSON、缺键、重复 id、空名、`unfiledCollapsed` 非 `true` 或零文件夹、`unfiledName` 非字符串/空串或零文件夹、失效 membership、切库键隔离、localStorage 不可写——均降级不崩；上传新文档入未分类；删除文档后组全选框与分组无残留；删最后一个文件夹一并丢弃 `unfiledName`。
10. **门禁**：`node --check client.js`；`src/*.ts` strip-types 全过（预期零改）；冒烟默认与 `SMOKE_HOSTLESS=1` 全绿；真 DSH 整重启后按本清单手验（候令）；`deer-flow` 主树与 `harness-rag` 引擎零 diff。

- 不做 agent 工具暴露文件夹、不做跨端/跨 profile 同步。
- 不做组行吸顶、不做表头变文件夹栏、不做全局收起（D4b 留作另立，不复用名称表头）；不做名称表头一职两用。
- 不给名称以外的表头加点击排序；其他表头继续走列菜单 chevron。
- 不改列集合、列偏好、排序键、行菜单既有项、上传/重复检测、切片抽屉。

## 8. 升级路径（本地 → 引擎，非本对）

- 同一份 `{ folders, membership }` 可原样抬成服务端模型：`kb_folders(id, kb_id, name, created_at)`＋`documents.folder_id`（可空，空＝未分类）；迁移从当前 head 0019 顺接；folders CRUD＋文档移动 API；插件 `kb_proxy.ts` 增 op。
- 引擎命中条件：需要跨端/跨 profile 保留，或要让 agent/检索按文件夹工作。出现任一需求时另立 spec/plan，不在本对预埋半套 API。
- 升级时仍不动检索逻辑：`folder_id` 只是元数据；除非明确要做「按文件夹检索」，那是另一个功能面。
