2. **抽屉体系**：首页=未分组＋用户自建抽屉（每卡至多一屉）；localStorage 分区，键照工作台 `deerflow.knowledge.card-drawers.{kbId}.v1`；12 图标＋12 色；新建/编辑/删除（删除不确认，卡片回首页）／收起（hidden，从「全部抽屉」下拉恢复并置顶）；移动单卡与批量；行图标与阅读抽屉头部跟随归属；当前标签过滤。
3. **头部、选择与计数**：头行＝`[chevron] [便签 我的条目 (N)] │ [抽屉A ×] │ [抽屉B ×] [+] ──垫片── [▦全部抽屉] [☑全选]`；标签溢出裁切、行内不横滚；计数取列表 `total`；勾选＝hover 淡入/选中常显、头部全选（含 indeterminate）、右键即选中；过滤即清选择、**切标签也清选择**（工作台切换标签不清，选中集跨抽屉残留——批量删除会误伤看不见的卡；按意图修正，登记 §6）；搜索仍限当前标签（工作台同款）；空态/无匹配照工作台。**同轮补（10-18 他令）**：生成条目区底部批量条退役（照工作台 2026-09-02 裁法），更新所选/删除所选/取消选择改由右键两态菜单承载（单选=打开/编辑/更新/取消/删除；多选=已选 N/更新所选/取消选择/删除所选）。
4. **条目编辑（E3 收口，10-18 他令并入）**：单行右键与行 ⋯「编辑条目」→ 取详情 → 面板内双栏编辑器（主内容区＋补充层，宽 600）；主内容可被下次生成覆盖、补充层永久保留并作为生成方向（提示逐字照工作台）；保存 PATCH 主内容＋补充层，成功 toast＋关窗＋刷新列表，失败停留并 toast；空主内容禁存。

新建入口照工作台逐处：首页标题右键＝新建卡片（未分组）；内容区空白右键＝新建卡片（当前标签）；抽屉标签右键＝新建卡片（该抽屉）/编辑/删除抽屉；头行 `[+]`、空白垫片右键、全部抽屉下拉底部＝新建抽屉；百科工具栏 ⋯＝新建抽屉＋新建卡片。

## 4. 验收

1. **CRUD 全链**：各处入口新建；编辑回填全文；标题或正文空白禁存；保存失败停留；混搜开→关→开向量生命周期正确（真栈：开后被 wiki 检索命中、关后不命中）；删除单卡/批量（确认文案与计数、部分失败提示、选择清理）。
2. **抽屉体系**：新建/编辑/删除/收起/恢复；12 图标与 12 色；每卡至多一屉；切换 KB 后按库隔离；移动单卡/批量；删抽屉卡片回首页；行图标与阅读抽屉跟随归属；刷新后分组保持（localStorage）。

## 6. 缺口登记

- 分组只在本机（localStorage）——工作台同款；换机/清缓存后分组丢失，卡片本身不受影响。
- 首屏 200 条上限（工作台 50）；超过 200 张没有分页器，另案。
- 批量删除是 N 次逐张删除；无服务端事务（工作台同款）。
- 搜索只覆盖已加载的 200 张，且限当前标签（工作台同款）。
- 宿主 `Menu` 支持 `submenu`（「移动到抽屉」）；无宿主冒烟回退需补二级渲染，否则移动入口降级为扁平抽屉名列表（仅在缺件环境出现）。
- 宿主子菜单恒向右展开（`left:calc(100%+10px)`）且只夹父菜单、不夹子菜单；插件在父菜单右缘余量不足（163 最小宽＋10 间距＋12 边距）时给宿主 list 加 `.hrag-ctxmenu-subflip`，把子菜单镜像到左侧（`DocContextMenu` 与 `DshMenu` 共用；宿主件零改）。
- 阅读抽屉在打开期间不跟随后台分组变化（工作台用 hook 状态同款，窗口内不刷新）。
- 切标签清选择＝有意偏离工作台（工作台 `setActiveTab` 不清选中集，跨抽屉批量删除会命中不可见卡）；插件按安全意图修正。
- `Modal` 不采用（portal 越出面板）；`Switch` 缺件回退自绘，外观以宿主 Switch CSS 为准。
- 本对已完成 E3 条目编辑（10-18 他令并入）；仍不动：卡片正文 Markdown；条目区批量条已退役（选择状态保留，动作改右键两态）。
