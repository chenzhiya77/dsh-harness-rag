# Harness RAG 等价移植对照（工作台 ↔ DSH 插件）

> 口径：**记录形**（2026-10-19 T6 D1）——逐项记录「工作台知识库页 ↔ DSH 插件面」的实际状态，作为验收与演进依据，不是强制等价闸。
>
> 状态四值：
> - **等价**＝功能可达且行为一致（交互细节可因宿主组件差异微调）
> - **精简**＝功能可达、交互或呈现简化（附差异说明）
> - **不做**＝明确不提供（必附理由与归属）
> - **宿主侧**＝该项由 DSH 宿主自身提供/治理，不属插件面
>
> 对照原型：本项目工作台 `deer-flow/frontend/src/components/workspace/knowledge/`；实现：`client.js`＋`src/`（本仓）。数据面两边同源（同一 knowledge 服务 REST）。

## 12. 宿主侧与明确不做

| 项 | 归属 | 理由 |
|---|---|---|
| 对话引用标记/引用源 | 宿主侧 | 工作台在聊天答案内渲染知识引用；DSH 对话呈现归宿主，插件不注入 |
| 对话引用锚块提示（`anchor-block-notice`/锚点确认） | 宿主侧 | 同上：引用锚定属工作台对话组件；插件的锚片预览只服务召回面板 |
| 独立整页（导航入口＋路由） | 不做 | DSH 无「主区整页」槽；右栏面板可达且可全屏/浮动 |
| 面板内置对话 | 不做 | 10-14 裁定：对话主模型各自宿主治理 |
| 像素级视觉对照 | 不做 | 本表记功能面，不记观感；观感按宿主组件词汇对齐 |
