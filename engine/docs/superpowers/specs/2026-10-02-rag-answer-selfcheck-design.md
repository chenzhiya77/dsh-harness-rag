## 1. 机制

### 1.0 一眼看懂

**现状（本件之前）**：「检索是否充分」无任何显式检查——首轮结果弱时，模型要么直接拒答（误拒面），要么拿预训练知识硬答（编造面）。

**本件之后**：事实性回答在给出前，模型内部对照覆盖/支撑两项自查；不足则按有界阶梯补检；补检后仍不足按拒答策略处理（干净拒答，或部分作答 + 缺口声明）。

```
改的（SOUL.md 两处）                          不改的
──────────────────────────────────────       ──────────────────────────────
① 新增「作答前自查」节                         检索工作流 5 条（向量保底 / wiki 例外 / 图谱 / 深度模式 / 未绑定）
  （覆盖/支撑 + 补检阶梯 + 轮次预算 + 出口）    拒答策略其余两条（禁编造 / 归纳须标引用）
② 拒答首句触发条件改写                         工具实现 / 中间件 / 前端 / 配置（零动）
  「检索结果与问题无关…」→「自查与补检后…」
```

### 1.1 条款（SOUL.md「作答前自查（内部判断，不写入回答）」节）

1. **覆盖**：问题点名或明确要求的每个要素都有证据落点。
2. **支撑**：拟写出的每条事实性结论都能直接落到某条检索证据上，不需要用预训练知识补齐。
3. **正向停止**：两项检查通过时直接作答，不为补检而补检。
4. **有界补检**：首轮之外，换路与换问法各最多一次，合计不超过两次工具调用轮——
   - 第一步换路：向量偏弱 → 关系题改 `graph_search`、概念题改 `wiki_search`；`wiki_search` 未中/不足 → 按检索工作流第 2 条回补 `hybrid_search`。
   - 第二步换问法：更具体的实体名/术语/同义表述重写；复合问题拆子问题分别检索。
   - 同一查询不得原样重复调用。
5. **出口**：补检后仍不足 → 按拒答策略：告知"知识库中没有找到相关内容"；或仅回答有证据支撑的部分并说明缺口范围（部分作答=本次裁定的新策略，非原拒答派生）。
6. **终止态排除**：未绑定知识库 / 无访问权限 / 依赖不可用 / 后续出现的检索暂停**不属于"证据不足"**——不触发补检、不计入轮次；如实告知（按工具返回的提示），不反复重试。

### 1.2 关键措辞与理由（修补动字前先读这列）

| 措辞 | 防的退化 / 理由 |
| --- | --- |
| 「问题点名或明确要求的每个要素」 | 「每个关键要素」无边界 ⇒ 无限扩检 |
| 「不为补检而补检」 | 最典型退化=每问必补检、成本与延迟翻倍 |
| 「首轮之外，换路与换问法各最多一次，合计不超过两次工具调用轮」 | 原稿计数歧义（首轮算不算、两种手法各一次还是合计一次）⇒ 一次绑死 |
| 「或仅回答有证据支撑的部分，并说明缺口范围」（保留） | 部分作答是新策略，用户审查时裁定保留 |
| 删除原「冲突」检查项 | 证据矛盾≠检索不足、重检解决不了；且与「回答风格」条逐字重复 |
| 终止态按前瞻写（含「检索暂停」） | 当前代码无此状态（v3 落地才用得到）；防「把不可用当证据不足」反复重试 |

## 2. 边界（有意不做——修补时勿当缺陷）

- **无评估器/编排器**：自查=模型内部判断（软、不写入回答），无结构化信号输出、无代码消费；保持主 spec §1 两级嵌套原则。
- **不强制循环**：单补充轮上限即一期边界，不做「自评→补检→循环」的硬循环。
- **硬编排仍属二期**：三路强制并行 + 统一 rerank（主 spec §4.7、D5 分格预算）未动、未预先实现。
- **误拒/漏补量化评估**：题组（可答/不可答成对）+ 判读代码 + 趋势三件已评估，**用户裁暂缓（2026-10-02：「只是优化，不是指标」）**——非漏项。
- **与 ToolProgressMiddleware 的分工**（`middlewares/tool_progress_middleware.py`，RFC #3177）：本件在模型侧（生成前自查）；middleware 在结果侧（工具结果停滞计数 → `[PROGRESS HINT]`）。三用例中后者均未触发。

## 3. 旋钮（预期内的修补入口）

| 旋钮 | 现值（SOUL.md 原文） | 改动影响 |
| --- | --- | --- |
| 补检轮次预算 | 「各最多一次，合计不超过两次工具调用轮」 | 调大=更贵更慢；调小=误拒面回涨 |
| 换路映射 | 关系题→`graph_search`；概念题→`wiki_search`；wiki 未中→回补 `hybrid_search` | 与检索工作流第 2 条绑定；影响路径选择 |
| 正向停止句 | 「不为补检而补检」 | 删除向「每问必补检」退化 |
| 部分作答出口 | 「或仅回答有证据支撑的部分，并说明缺口范围」 | 删除=回到纯拒答口径 |
