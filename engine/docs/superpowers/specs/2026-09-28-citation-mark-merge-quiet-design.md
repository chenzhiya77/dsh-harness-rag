## 1. 问题与范围

**现状**（`citation-mark.tsx` + `rehype-citation-marks.ts`）：模型写的 `[n]` 被 rehype 逐个拆成独立 `<sup>`，各自渲染成小灰胶囊——① 连续引用不合并、不排序（「…超时自动放弃）⁷ ⁵」，序号非单调，读着像乱码）；② 裸灰小方块在中文正文里读不出"可点的引用"，密集出现时像排版噪声。

**本对之后**：相邻标号合成一个胶囊、按显示序号升序去重（「⁵·⁷」）；胶囊 hover 叠放多张来源预览、点击高亮全部对应卡片；灰系默认降一档（hover 恢复并提亮）。

```
改的                                        不改的
──────────────────────────────────        ─────────────────────────────
① rehype 相邻 sup 分组（空白才相邻）       SOUL.md 引用密度（逐条事实标注）
② sup 渲染层合并胶囊（升序去重）           评测口径（ragas_eval 数 [n]）
③ 跳转事件 index → indices（两端同改）     来源条卡片形态 / grouping
④ 胶囊样式灰系降一档 + hover 恢复          丙·段末聚合（明确不做）
⑤ 用例（rehype + dom 结构钉）              后端零改动
```

**根因**：`rehype-citation-marks.ts` 对 `[n]` 逐个建 sup、`citation-mark.tsx` 的 `CitationSupRenderer` 各自独立渲染——渲染层看不到兄弟节点，合并必须落在 rehype 层（它持有整棵树）。

## 2. 裁定（四条，2026-09-28 全按推荐）

| # | 在问什么 | 裁定 | 判据 / 选错后果 |
| --- | --- | --- | --- |
| ① | 多近算"相邻" | **甲：两个 sup 之间只有空白（含零宽）才算相邻** | 中间有正文词/标点/整句的不合并——过宽会把不同论断的引用粘一团（丢粒度），过窄治不了隔空格的「⁷ ⁵」 |
| ② | 合并胶囊点了跳谁 | **甲：hover 多张预览卡叠放；点击展开来源条并高亮全部对应卡片**（chunk 卡沿用自动展开，取匹配里第一张 chunk/manual） | 只跳第一个=其余来源够不着；合并后不可点=像坏了 |
| ③ | 「⁷ ⁵」「⁷ ⁷」显示成什么 | **甲：按显示序号升序去重（→「5,7」「7」，逗号分隔）** | 这正是要修的乱码感，无悬念；分隔符不用 `·`（悬在中线） |
| ④ | 标号安静到什么程度 | **甲：维持灰系、默认降一档（更淡），hover 恢复并提亮** | 彩色在密集标注下更吵；具体多淡多小由他真浏览器观感拍板（几何/观感阈值他拍） |

## 3. 机制

### 3.1 rehype 层：相邻分组（裁定①）

- 只合并**本插件自己产出的** sup（携带 `dataCitationIndex`）；源码里手写的 `<sup>` 不碰。
- 同一父节点内，连续 sup 之间仅隔空白文本节点（含零个文本节点）⇒ 合成一个 `<sup data-citation-indices="7 5">`（原始 citation_no 按书写序、空格分隔）；跨元素边界（如隔着 `<strong>`）不合并。
- 单个 sup 保持现状 `data-citation-index`（旧形状零变化，旧用例语义延续）。

### 3.2 渲染层：合并胶囊（裁定③）

- `createCitationSupRenderer` 对组内每个 raw no 走既有解析（`citation_nos` 包含 → 显示序号=来源条排序位次），然后**按显示序号升序 + 去重**；单个解析出一个的按单标渲染。
- 显示格式：`5,7`（逗号分隔；`·` 悬在中线、上标小字号里读着怪）。胶囊前后留白贴合（删 `min-w`、`mx/px` 1px）。
- 解析不出的 raw no（陈旧标号）沿用今天的裸 `<sup>` 兜底逐个显示；组内部分解析不出时，可解析的照常成胶囊、其余裸 sup 并列——**内部 citation_no 永不换算成"看起来像显示序号"的数字**。
- aria-label：多个来源 = 既有 `sourceMarkAriaLabel` 逐个拼接（「引用 5：A、引用 7：B」），不加 i18n 新词。

### 3.3 交互（裁定②）

- `CitationJumpDetail` 从 `{messageId, index}` 改为 `{messageId, indices: number[]}`——单标即 `[index]`，两端（`citation-mark.tsx` 派发 / `kb-citation-sources.tsx` 监听）同一变更集内同改，不做兼容层。
- 来源条：`highlightNumber` → `highlightNumbers`，匹配组全部点亮（`data-citation-highlight` + ring）；自动展开 chunk 卡取匹配里第一张 chunk/manual；滚动定位第一个高亮（仍限定本条来源区内）。
- hover：组内每张来源一张 `CitationPreviewCard`，纵向叠放。

### 3.4 降噪（裁定④）

- 胶囊（单/合共用）默认态灰系降一档（`bg-muted/40` + `text-muted-foreground/70` 量级），hover 恢复并提亮（`hover:bg-muted hover:text-foreground` 量级）；上标尺寸/对齐（`align-super` `text-[0.7em]`）不动。
- 最终观感值由他真浏览器验收后拍——用例只钉结构（有 hover 态类、默认态更淡的类存在），不钉具体色阶。
